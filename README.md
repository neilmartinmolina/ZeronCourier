# ZeronCourier

The browser helper is named **ZeronCourier — Send and Bring Back** (version 1.3.1). When upgrading from a differently named helper, disable the old script in Tampermonkey before installing this one so only one helper runs.

A lightweight local bridge from an existing ChatGPT browser conversation to a selected Zeron agent chat. No n8n, VPS, or model API key is required. It uses `zeron mcp`; Zeron and the host PC must stay running.

## Features

- Send visible Markdown/code blocks to Zeron without manually pasting them. Review and confirm before sending.
- Copy listener and a manual paste editor for other instructions.
- Live status: working spinner, queued, needs input, connection errors, and completed report readiness. Polls every 8 seconds while visible and 25 seconds in background tabs.
- Retrieve reports into an empty ChatGPT composer as unsubmitted drafts. Existing drafts are preserved.
- Duplicate suppression and persistent delivery tracking. Busy chats and uncertain deliveries block new tasks.
- Account switching and agent permission answers stay in Zeron.

## Requirements

Node.js 20+, a Zeron build exposing `zeron mcp`, and Tampermonkey in the browser used for ChatGPT. Windows has background start/stop scripts; other platforms can run `npm start` in a terminal. There are no npm dependencies to install.

## Setup

1. Download or clone this repository and keep Zeron open.
2. Configure the executable and exact project name. On Windows PowerShell:

   ```powershell
   $env:ZERON_EXECUTABLE = 'C:\path\to\zeron.exe'
   $env:ZERON_PROJECT_NAME = 'Your Project Name'
   & '.\Start ZeronCourier.ps1'
   ```

   Alternatively, if `zeron` is already on PATH, set the project name and run `npm start`. The default project name is `InternTrack`; change it to your own project. On first startup the bridge saves its defaults and generates a private pairing token in `work/zeroncourier-runtime/config.json`. You can edit the executable and project name in that file and restart.
3. Open `http://127.0.0.1:8787` in your ChatGPT browser. Install Tampermonkey from its official marketplace via https://www.tampermonkey.net/ and follow its browser-specific userscript setup instructions.
4. Click **Install browser helper** and confirm installation. If source appears instead, copy it into a new Tampermonkey script and save.
5. Refresh ChatGPT and select the **Zeron destination chat**. The open ChatGPT conversation is the source; its title does not need to match the destination.

To update the helper, install it again from the local page and refresh ChatGPT. To stop the Windows background bridge, run `Stop ZeronCourier.ps1` in a PowerShell session able to inspect process metadata.

## Usage

Click **Send this block to Zeron** beside an assistant code block, or click the block's **Copy** button. The helper displays **Send “the instruction title” to Zeron?** and preloads the full text. Confirm **Send this instruction** to send through the bridge. If text is not accessible in an embedded view or attachment, use **Paste instruction**.

Blue indicates working/sending/fetching; purple indicates queued; amber indicates input needed or uncertain delivery; red indicates an agent or connection error. Green **Report ready** indicates a new completed response for a zeroncourier task. **Latest report available** identifies an existing completed response. Click the report button to insert it as a draft and review it before submitting to ChatGPT.

The copy listener reads the clicked block or native copy-event text, without polling the system clipboard. ChatGPT page changes can affect detection and composer insertion. The helper offers a copyable report if it cannot insert a draft.

## Keep private data out of GitHub

Publish the source template, **not the paired script generated by your running bridge**. That generated script contains a private token. The included `.gitignore` excludes runtime data, logs, generated userscripts, and screenshots. Do not force-add those files. A fresh clone generates its own token.

The server binds only to `127.0.0.1:8787`, requires bearer authentication for API calls, and checks Host and Origin headers. Do not expose the bridge publicly. This version has no phone endpoint, unattended task loop, or automatic account switch. Existing ChatGPT and agent usage limits apply. This is a custom convenience integration, not an official ChatGPT or Zeron product.

## Uncertain delivery

Check the exact chat in Zeron to determine whether the instruction arrived; finish or cancel it there. Stop the bridge, then run:

```powershell
node 'Resolve Delivery.mjs' CHAT_ID --confirmed-reviewed-in-zeron
```

Restart afterward. This marks uncertainty reviewed and retains duplicate records; it never resends an instruction.

## Tests

```sh
npm test
```

Tests use a mock Zeron engine and cover project restrictions, duplicate suppression, concurrency, uncertain delivery, task/report correlation, live states, HTTP access controls, and Markdown normalization/title detection. They do not send tasks to a real agent.
